Scheduling Logic

Alert Windows: Each document has a custom "Notice Lead Time" (e.g., 30, 60, or 90 days). An item enters the queue only when its expiry date falls within this window.

Audit Trail Protection: Sending a notice updates the document's Last Notified timestamp and appends a permanent record to its history log to ensure GCP compliance.

Cooldown Period: To prevent spamming, the system will not flag an item for batch processing if it has already been notified within the last 7 days.
